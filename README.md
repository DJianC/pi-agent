# PI-Desktop

[简体中文](README.zh-CN.md)

PI-Desktop is a local-first AI coding workspace for macOS, Windows, and Linux. It supports persistent project sessions, multiple model providers, and agent workflows that can be extended with MCP and plugins.

Source snapshot from the [PI-Desktop 0.24.x development line](https://github.com/vastsa/PI-Desktop/tree/7254a04529ff4392045c2d7f0b653580bf69b4d3).
